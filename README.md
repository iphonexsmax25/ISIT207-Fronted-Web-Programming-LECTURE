# ISIT207 Front-End Web Programming Code Practices

This repository is created to store front-end web programming practice exercises, coding challenges, and self-learning activities. It serves as a reference for students to improve their coding skills through hands-on practice.

Each branch corresponds to a specific topic, lesson, or practice set, making it easy to organize and access exercises.

## 📁 How to Access Practice Codes

- Navigate to the repository.
- Click the **branch dropdown menu** (top-left).
- Select the branch for the practice you want to view:
  - Practice-1 → Code for Practice 1
  - Practice-2 → Code for Practice 2
  - Practice-3 → Code for Practice 3
  - Practice-4 → Code for Practice 4
  - (and so on for all practices)

## 📁 Opening and Running the Files

It is recommended to use **Visual Studio Code (VS Code)** together with the **Live Server** extension to run and test the HTML, CSS, and JavaScript files.

Simply clone the repository, switch to the desired branch, and open the project folder in VS Code.
