# ISIT207-Front-End-Web-Programming-Lectures

This repository is created to upload front-end web programming lecture codes, labs, and examples for backup and to allow students to reference the code.
Each branch corresponds to a specific lecture or week, making it easy to access the examples you need[cite: 1].

---

## 📁 How to Access Lecture Codes

1. Navigate to the repository.
2. Click on the **branch dropdown menu** (top-left).
3. Select the branch for the lecture or topic you want to view:
   * `Lesson-1` → Code examples for Lecture 1 
   * `Lesson-2` → Code examples for Lecture 2 
   * `Lesson-3` → Code examples for Lecture 3
   *(and so on for each lecture)*[cite: 1]

---

## 📁 Opening and Running the Files

* It is recommended to use **Visual Studio Code (VS Code)** along with the **Live Server** extension to open and run the HTML/CSS/JavaScript files.
* Simply clone the repository, switch to the desired lecture branch, and open the project folder in VS Code[cite: 1].

---

## 🛠️ Steps

### 1. Download/Clone the Repository
* **Option A:** Click the green **Code** button $\rightarrow$ **Download ZIP** $\rightarrow$ Extract the files[cite: 1].
* **Option B:** Use Git:
  ```bash
  git clone [https://github.com/your-username/ISIT207-Web-Programming-Lectures.git](https://github.com/your-username/ISIT207-Web-Programming-Lectures.git)
  ```[cite: 1]

### 2. Open VS Code
* Launch **Visual Studio Code** on your computer[cite: 1].

### 3. Open the Project
* Go to **File $\rightarrow$ Open Folder...**[cite: 1]
* Browse to the folder where you extracted/cloned the repository[cite: 1].
* Select the project folder and click **Open**[cite: 1].

### 4. Run the Code
* Right-click on the `index.html` file or relevant HTML page[cite: 1].
* Choose **Open with Live Server** (or click **Go Live** at the bottom-right status bar of VS Code) to execute and view the web page in your browser.
